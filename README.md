# Pixelgah Launcher

A launcher-style demo for a multi-category game store (Persian, RTL). Single self-contained `index.html`.

All products, prices, reviews and codes are sample content.

## Hokm

`hokm/` holds a separate project: a four-player Hokm card game against three bots (Persian, RTL). Single self-contained `hokm/index.html`, served at `/hokm/` on GitHub Pages.
