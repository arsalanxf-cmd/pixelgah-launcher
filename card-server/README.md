# سرور آنلاین میز ورق

این پوشه سرور بازی آنلاین است: صفحه‌ی بازی را نشان می‌دهد و همه‌ی میزهای آنلاین را اداره می‌کند. کارت‌ها روی سرور بُر می‌خورند و هر بازیکن فقط کارت‌های خودش را می‌بیند، پس کسی نمی‌تواند با دستکاری مرورگر دست بقیه را ببیند.

بازی‌های آنلاین: حکم (۲، ۳ و ۴ نفره)، شلم، پاسور (۲ و ۴ نفره)، دل، هفت‌خبیث و رامی. پاسیانس یک چالش روزانه دارد که همه همان دست را بازی می‌کنند.

امکانات:
- اتاق با کد دعوت و لینک
- پیدا کردن حریف تصادفی، و اگر کسی نیامد، شروع با ربات
- ربات به‌جای صندلی‌های خالی و به‌جای کسی که بازی را ترک کند
- وصل شدن دوباره بعد از قطعی اینترنت، وسط همان دست
- زمان محدود برای هر حرکت؛ اگر تمام شود، سرور به‌جای بازیکن بازی می‌کند
- جدول امتیاز هر بازی (امتیاز ELO فقط در بازی آدم با آدم تغییر می‌کند)

نیازمندی: Node.js نسخه‌ی ۱۸ یا بالاتر، یا Docker.

## راه ۱: سرور مجازی (VPS) با Docker

روی سرور:

```bash
git clone https://github.com/arsalanxf-cmd/pixelgah-launcher.git
cd pixelgah-launcher/card-server
docker compose up -d --build
curl http://127.0.0.1:3000/health
```

اطلاعات بازیکن‌ها و جدول امتیاز در volume به نام `cards-data` می‌ماند و با به‌روزرسانی پاک نمی‌شود.

به‌روزرسانی بعدی:

```bash
cd pixelgah-launcher && git pull && cd card-server && docker compose up -d --build
```

## دامنه و HTTPS

یک رکورد A برای دامنه (مثلاً `cards.example.com`) به IP سرور بسازید، بعد Caddy را نصب کنید و فایل `deploy/Caddyfile` را با دامنه‌ی خودتان در `/etc/caddy/Caddyfile` بگذارید:

```bash
sudo systemctl reload caddy
```

Caddy گواهی HTTPS را خودش می‌گیرد و اتصال WebSocket را هم رد می‌کند. اگر nginx دارید، نمونه‌اش در `deploy/nginx.conf` است.

بعد بازی روی `https://cards.example.com` باز می‌شود.

## راه ۲: بدون Docker

```bash
cd card-server
npm ci --omit=dev
PORT=3000 node server.js
```

برای اینکه بعد از ری‌استارت سرور خودش بالا بیاید، از `deploy/mize-varagh.service` (systemd) یا pm2 استفاده کنید.

## راه ۳: سرویس‌های میزبانی Node.js

این پوشه را به‌عنوان یک برنامه‌ی Node.js مستقر کنید. دستور اجرا `node server.js` است و پورت از متغیر `PORT` خوانده می‌شود. یک دیسک دائمی بدهید و `DB_FILE` را به فایلی روی آن بگذارید، وگرنه با هر استقرار جدول امتیاز پاک می‌شود. سرویس باید WebSocket را پشتیبانی کند.

## تنظیمات

| متغیر | پیش‌فرض | کار |
|---|---|---|
| `PORT` | `3000` | پورت HTTP و WebSocket |
| `DB_FILE` | `data/db.json` | فایل ذخیره‌ی بازیکن‌ها و امتیازها |
| `QUICK_WAIT` | `25000` | چند میلی‌ثانیه در صف حریف تصادفی صبر شود تا با ربات شروع شود |

`ASK_SCALE` و `SHORT_GAMES` فقط برای تست‌اند و نباید روی سرور اصلی تنظیم شوند.

## نسخه‌ی گیت‌هاب

صفحه‌ی گیت‌هاب (`/hokm/`) جدا از این سرور است. برای اینکه حالت آنلاین آن هم به این سرور وصل شود، هنگام ساختن صفحه `ONLINE_WS` را برابر `wss://cards.example.com/ws` بگذارید. ساده‌تر این است که بازیکن‌ها مستقیم آدرس سرور را باز کنند.

## ساختار

- `server.js`: سرویس HTTP، WebSocket و پیام‌ها
- `lib/room.js`: اتاق‌ها، صندلی‌ها، ربات‌ها، صف حریف تصادفی و وصل شدن دوباره
- `lib/store.js`: ذخیره‌ی بازیکن‌ها، امتیازها و چالش روزانه در یک فایل JSON
- `games/*.js`: قانون‌ها و ربات هر بازی؛ سرور هر حرکت را بررسی می‌کند
- `public/`: صفحه‌ی بازی و فونت‌ها (Vazirmatn و Oswald، هر دو با مجوز OFL)
